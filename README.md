## Примеры использования функций:

+ Модуль category

**Создан класс Category** 

Класс для представления категории продукта
Имеет следующие свойства следующие свойства:

название (name),
описание (description),
список товаров категории (products).

    
+ Модуль product

**Создан класс Product** 

Класс для представления категории продукта
Имеет следующие свойства следующие свойства:

название (name),
описание (description),
цена (price),
количество в наличии (quantity).


+ Модуль utils

**def read_json(JSON_FILE) -> dict**
Функция читает JSON файл.


**def create_objects_from_json(data)**
Функция создает объекты классов.


+ Модуль lawn_grass_product

**class LawnGrass(Product)**
Дочерний класс 'Трава газонная' принимающий родительский класс Product


+ Модуль smartphone_product

**class Smartphone(Product)**
Дочерний класс 'Смартфон' принимающий родительский класс Product


+ Модуль base_product

**class BaseProduct(ABC)**
Абстрактный класс, является родительским для класса продуктов.

 
+ Модуль print_mixin

**class PrintMixin**
Класс-миксин, который будет при создании объекта,
печатать в консоль информацию о том, от какого класса и с какими параметрами был создан объект.


+ Модуль main
Проверка выводов category.py и product.py

## Тестирование:
  

Тесты созданы в пакете tests с использованием библиотеки pytest.
В тестах используются фикстуры. 
  
**Запуск тестов:**
```bash
pytest

```

**Запустить тесты с выводом покрытия в терминал**
```bash
pytest --cov=src --cov-report=term-missing

```
